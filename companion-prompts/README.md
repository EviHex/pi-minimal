# @pi-minimal/companion-prompts

Adds a per-extension prompt file to the system prompt, only when that extension
is loaded. Files are matched by the frontmatter `id`. See `AGENTS.md` for details.

## Install

Not on npm yet. Clone the repo and install from the folder:

```sh
git clone https://github.com/EviHex/pi-minimal
pi install ./pi-minimal/companion-prompts
```

## Settings

None.
